YOUYOU V7.5 — FINAL LANDING ENGINE LOCK

WHAT CHANGED
1) Workspace preview is now an iframe running the SAME full HTML renderer as Export + Published URL.
   - Mobile button changes the iframe viewport to a real 390px phone width.
   - Old dashboard CSS can no longer stretch the slider or override landing-page colors.
2) Legacy slider min-height is neutralized.
3) Published pages now carry a renderer version.
   - Older published snapshots show "Live design update required" / "Update live design".
   - Click that button once to regenerate the existing public URL with the current renderer.
4) Media shared by duplicated pages is detached rather than auto-deleted from Storage.
   This prevents deleting a photo/video in one duplicate from breaking another page.
5) Publish security is tightened with an RPC-only public read path so anonymous visitors cannot read draft JSON or internal landing-page fields.
