YOUYOU V8.4 — PREMIUM PRODUCT OPTIONS UI

ROOT CAUSE FOUND
- V8.3 premium commerce CSS existed in style.css, but the standalone landing snapshot generated by landingExportHtml() did not include the newer V8.3 color/option/bundle styles.
- The published-page runtime color lock also targeted every .lp-lead-form button, so color, size, quantity and bundle controls were repainted as the main accent CTA.
- Result: giant purple controls, checkmarks visible on non-selected options, and clicks looked non-functional even though aria-pressed/is-active was changing.

V8.4 FIX
- Renderer bumped to 8.4.0.
- Form CTA isolated from commerce controls (lp-lead-submit / direct-child submit selector).
- Public runtime no longer paints every button inside the form as a CTA.
- Premium compact tile system added to BOTH app style.css and generated landing snapshot CSS.
- Color tiles: small transparent/background-matched cards + small color square + one visible check only on selected choice.
- Size/Weight/Volume/Units/Custom: compact square-ish tiles, selected border + subtle tint + check.
- Bundles: compact cards with selected feedback.
- Quantity: compact transparent - 1 + stepper; no giant accent circles.
- Selection CSS uses both .is-active and aria-pressed=true for robust visible feedback.
- Public publisher runtime marker/header bumped to 8.4.0.
- No SQL required.

IMPORTANT
Existing published pages store HTML snapshots. After deploying V8.4, open the page in My Pages / Continue Editing and use Update live page once so the stored snapshot receives renderer 8.4.0.
